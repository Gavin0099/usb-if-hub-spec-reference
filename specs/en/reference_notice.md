# Independent Reference Notice

This site is an independent, unofficial engineering reference based on
publicly available USB specifications. It is not affiliated with or endorsed
by USB Implementers Forum, Inc.

## Authority and source

USB specifications remain the authoritative source for normative requirements.
This site contains independently authored summaries, structured lookup tables,
and engineering context. It does not reproduce or replace the official
specifications and does not establish firmware behavior, USB-IF certification,
or project-specific compliance.

Official source entry points:

- [USB 2.0 Specification — USB-IF Document Library](https://www.usb.org/document-library/usb-20-specification)
- [USB-IF Document Library](https://www.usb.org/document-library)

Each reference page should identify its specification family and section scope
when making a normative-looking statement. A source link is an attribution and
authority aid; it is not a claim that this repository has reproduced or
semantically verified the linked document.

## Public-content boundary

The site may state protocol constants, field names, bit positions, request IDs,
and independently written summaries. It must not reproduce full specification
sections, verbatim paragraphs, original figures or diagrams, large original
tables, or the complete specification sequentially.

## Licensing boundary

Specification names, trademarks, and associated rights belong to their
respective rights holders. Third-party standards and trademarks are not
licensed by this repository. A repository-wide license statement must not be
read as licensing third-party material.
