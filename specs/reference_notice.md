# 獨立參考聲明

本網站是根據公開可取得的 USB 規格撰寫的獨立、非官方工程參考，與 USB
Implementers Forum, Inc. 沒有隸屬、認可或背書關係。

## 權威來源

USB 規格仍是規範性要求的權威來源。本網站提供自行撰寫的摘要、結構化查詢
表格與工程脈絡，不複製或取代官方規格，也不建立韌體行為、USB-IF 認證或
專案特定合規性的證明。

官方來源入口：

- [USB 2.0 Specification — USB-IF Document Library](https://www.usb.org/document-library/usb-20-specification)
- [USB-IF Document Library](https://www.usb.org/document-library)

各參考頁在提出看似規範性的敘述時，應標明規格家族與章節範圍。來源連結是
歸屬與權威界線的輔助，不代表本 repo 已重製或語意驗證該文件。

## 公開內容界線

本網站可以列出協定常數、欄位名稱、位元位置、request ID 與自行撰寫的摘要。
不得重製完整規格章節、逐字段落、原始圖表或圖示、大型原始表格，也不得依
完整規格順序重建替代版本。

## 授權界線

規格名稱、商標與相關權利屬於各自權利人。第三方標準與商標不由本 repo 授權。
repo 層級的授權聲明不得被理解為授權第三方素材。
